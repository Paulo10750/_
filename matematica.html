Equações do 1º Grau com 1 Incógnita: Teoria, Passo a Passo e Exercícios Resolvidos.

Como resolver equação do 1º grau com 1 variável

A forma geral da equação do 1º grau é:

ax + b = 0

Onde a e b são números reais, sendo que a ≠ 0 (a não pode ser 0).

Exemplo:

25 + 2x = -3x - 25

1º Passo:

Juntar todos os "x" (termos com variável) em um lado e todos os números sem "x" no outro lado.

25 + 2x + 3x + 25 = 0 → 5x + 50 = 0
2º Passo:

Colocar a variável "x" e o termo independente em lados diferentes da igualdade.

5x = -50
3º Passo:

Passar o coeficiente de "x" multiplicando ou dividindo para o outro lado.

x = -50 / 5
4º Passo:

Resolver a operação entre os números para encontrar o resultado final.

x = -10

Exercícios: Resolva as equações do 1º grau a seguir

a) 4x - 40 = 160
4x = 160 + 40
4x = 200
x = 200 / 4
x = 50
b) 28 - 3 - 7x = -35
25 - 7x = -35
-7x = -35 - 28 + 3
-7x = -60 - 3 = -63
7x = 63
x = 63 / 7
x = 9
c) 34 = 8x + 9x + 102
34 = 17x + 102
34 - 102 = 17x
-68 = 17x
x = -68 / 17
x = -4
d) 12 + 38 = 85 - 4x - 4
50 = 81 - 4x
4x = 81 - 50
4x = 31
x = 31 / 4
x = 7,75 (ou 31/4)
e) 9x = 90x - 9837
9x - 90x = -9837
-81x = -9837
81x = 9837
x = 9837 / 81
x = 121,44 (ou 9837/81)
f) 45x + 9000 = 40x + 8000
45x - 40x = 8000 - 9000
5x = -1000
x = -1000 / 5
x = -200
g) 36x = 198
x = 198 / 36
x = 11 / 2
x = 5,5
h) 495 - 3x = -180
-3x = -180 - 495
-3x = -675
3x = 675
x = 675 / 3
x = 225
i) 3x - 5x + 18 = 90 + 7x
-2x + 18 = 90 + 7x
-2x - 7x = 90 - 18
-9x = 72
x = 72 / (-9)
x = -8
j) 40 - 4(2 - x) = 0
40 - 8 + 4x = 0
32 + 4x = 0
4x = -32
x = -32 / 4
x = -8
